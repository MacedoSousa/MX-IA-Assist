\# MX Permissions





\## Default



All agents start with read-only access.





\## Allowed



Agents may:



\- analyze;

\- suggest;

\- explain;

\- generate drafts.





\## Restricted



Agents cannot:



\- send emails automatically;

\- delete files;

\- modify infrastructure;

\- change projects;

\- approve financial actions.





\## Approval Required



Human confirmation is required for:



\- external communication;

\- financial actions;

\- production changes;

\- destructive operations.
