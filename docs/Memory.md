\# MX Memory Architecture





\## Purpose



MX memory stores relevant information with context and ownership.





\## Memory Layers





\## Short Term Memory



Temporary conversation context.



Examples:



\- current task

\- current project

\- current discussion





\## Project Memory



Information related to projects.



Examples:



\- architecture decisions

\- technologies

\- tasks

\- documentation





\## Personal Memory



User preferences and information.



Examples:



\- communication style

\- learning preferences





\## Knowledge Memory



External information.



Examples:



\- documents

\- PDFs

\- repositories

\- manuals





\## Rules



Memory must have:



\- owner

\- context

\- timestamp

\- source





Sensitive information requires permission.
