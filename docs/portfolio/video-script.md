# MX Presentation Video / Vídeo de Apresentação do MX

## Creative direction / Direção criativa

A 60-second professional product pitch with a dark graphite background, electric cyan accents and clean technical typography. The tone is thoughtful, confident and human: MX is not presented as a magical replacement for people, but as a local assistant designed with intelligence, care and productivity. Use original abstract interface motion, the MX architecture diagram, terminal-style evidence and concise bilingual captions. Avoid displaying credentials, tokens, private IP addresses or real personal data.

## Storyboard — Portuguese narration

**Target duration:** 55–70 seconds.
**Format:** 16:9 for portfolio and LinkedIn; the same assets can be adapted to 9:16 later.
**Audio:** Brazilian Portuguese documentary-style narration, calm and confident, with restrained electronic ambience.

## Accessibility and privacy

The final video should include burned-in subtitles in Portuguese and an English-caption variant. Contrast must remain readable against the dark background. No real token, password, user email, local IP, database content or private conversation may appear in any frame. Terminal proof should show only endpoint paths, HTTP status, test counts and container names.
