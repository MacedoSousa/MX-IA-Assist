\# MX Core Entities





\## User



Represents a person using MX.





Fields:



\- id

\- name

\- role

\- permissions





\---





\## Workspace



Represents an isolated environment.





Examples:



\- Pedro

\- Kevelin

\- Family

\- Company





\---





\## Project



Represents an initiative.





Examples:



\- MedicSync

\- MX

\- Business Projects





\---





\## Memory



Stores relevant information.





Fields:



\- content

\- category

\- owner

\- importance

\- source





\---





\## Conversation



Stores interactions.





Fields:



\- user

\- workspace

\- timestamp

\- summary
